# Text Processor SaaS Application

A modern **Software as a Service (SaaS)** platform providing advanced text analysis features with a transparent, usage-based pricing model. This application allows users to process text efficiently while paying only for the computational resources they use.

---

## Features

### 🔍 **Text Analysis**

- Analyze text for word count, character count, and other useful insights.
- Get detailed resource usage statistics (CPU and RAM) for each transaction.

### 🧾 **Transaction History & Invoices**

- View detailed transaction history with information like CPU and RAM usage, credits deducted, and text processed.
- Download invoices for all transactions directly from your dashboard.

---

## Pricing

Our transparent, **pay-as-you-go** pricing model ensures you only pay for what you use:

- **CPU Usage:** ₹0.05 per second.
- **RAM Usage:** ₹0.03 per MB.
- **Base Service Fee:** ₹1 per transaction.

Users are notified of the resource usage and total cost after each transaction.

## Tech Stack

### **Frontend**

- **React.js**: For dynamic and component-based UI development.
- **Tailwind CSS**: Modern utility-first CSS framework for responsive and beautiful design.

### **Backend**

- **Node.js** with **Express.js**: RESTful APIs to handle user requests and transactions.
- **MongoDB**: To store user data, transaction history, and pricing information.

### **Others**

- **Axios**: For seamless HTTP requests.
- **JWT Authentication**: Secure user login and session management.
